## Cómo correrlo localmente
Solo abre `index.html` en el navegador — no necesita servidor ni instalación.

## Cómo publicarlo (GitHub + Vercel)
1. Sube esta carpeta a un repo nuevo en GitHub
2. Entra a vercel.com → "Add New Project" → conecta el repo
3. Framework: "Other" (sitio estático, sin build command)
4. Deploy — Vercel te da un link público al instante
5. Cuando tengas dominio propio (miasvillageofhope.com), lo conectas desde Vercel → Settings → Domains
